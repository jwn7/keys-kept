# 디자인 시스템

캔버스(최종 디자인, 8화면): https://claude.ai/artifact/KjaDp48c7yc3aoxnL79VrM
`apps/web/src/styles/tokens.css`에 아래 값을 그대로 옮긴다. 참고한 가이드: 모바일 UI 가이드(서윤/최철호), Consumer Web UI/UX 가이드(NN/G·Baymard·GOV.UK·WCAG 2.2 기반), Beyond the Template 2026–2030.

## 방향
- 축: **CALM × UTILITY**. 스타일: Quiet Luxury + Analog Editorial (추천 맥락 "기록·개인 관리").
- 브랜드 문장: "개발자도 못 보는 메모장." 조용하고, 종이 같고, 정확하다.
- DESIGN MIX = 목소리 1(정교·조용) + 시각 스타일 1(종이+먹+봉랍) + 인터랙션 규칙 1(상태는 항상 색+형태+텍스트).

## 타이포
- 제목(화면 제목, 메모 제목, 잠금 화면 문장): `--font-serif` 500–600, letter-spacing -0.02em.
- 본문: `--font-sans` 400, 15px(PC) / 16px(모바일), **line-height 1.7 이상** (한글 가이드 150%+).
- 보조 텍스트 12–13px, 색 `--muted` 이하로 내려가지 않음(대비 4.5:1 유지).
- 라벨 소제목: 11px, letter-spacing .06em, `--muted`.

## 컴포넌트 규칙
- **주 버튼은 화면당 1개** (`--accent` 배경, 흰 글자, 700). 나머지는 테두리 버튼 또는 링크. 같은 강조 레벨 반복 금지.
- 선택·정렬·주기처럼 옵션 ≤5개는 **세그먼트 컨트롤**(눌린 항목 `--ink` 배경 + 흰 글자). 드롭다운은 7개 이상일 때만.
- 상태 뱃지: 점(8px) + 텍스트 + 테두리, 색은 `--ok/--warn/--danger`. 색만으로 상태를 구분하지 않는다.
- 저장/동기화 피드백은 텍스트로("로컬 저장됨 · 방금 전"). 아이콘만 두지 않는다.
- 입력창: 높이 44–48px, 테두리 `--line-strong`, **지우기(×) 버튼 필수**, 포커스 링 2px `--accent`.
- 오류: 해당 필드 바로 아래에 "무엇이 왜 틀렸고 어떻게 고치는지" 한 줄 + 예시.
- 빈 상태: 설명 1줄 + 다음 행동 버튼 1개 ("첫 메모 쓰기", "필터 초기화").
- 로딩: 레이아웃 유지하고 스켈레톤. 화면을 가리는 스피너 금지.
- 위험 동작(삭제·연결 해제): `--danger` 테두리 버튼 + 확인 단계. 숨기지 않되 주 버튼 스타일로 만들지 않는다.
- 터치 타겟 44px 이상, 모바일 `완료`는 상단 내비게이션 우측(키보드에 가려지지 않게).
- 모바일 상단 바: 뒤로가기 1개 + 제목 + 컨트롤 1–2개까지. 브레드크럼 없음.
- 모션: 상태 전환 150–200ms, `prefers-reduced-motion`이면 전부 끔.

## 고유 패턴
- **"서버가 보는 것" 패널** (Memory Boundary 차용): 설정 동기화 섹션에 "✓ 볼 수 있음 / ✕ 볼 수 없음" 두 줄. 제로-널리지를 말이 아니라 화면으로 보여준다.
- 편집기 상단 작은 자물쇠 아이콘 + "이 기기에서 암호화됨 · 서버는 내용을 볼 수 없음".
- 충돌 사본: 목록 행 아래 `--accent-soft` 배경 작은 뱃지 "⚠ 충돌 사본 1개 · 폰에서 동시에 수정됨".

## 화면별 메모
| 화면 | 핵심 |
|---|---|
| PC 잠금 | 좌: 가치 문장 + 서버가 보는 것 2줄 / 우: 비밀번호 카드, 복구 경로 2개 노출 |
| PC 메인 | 3열(212 / 320 / 나머지). 목록은 `--surface-2`, 편집기는 `--surface`. 현재 메모는 왼쪽 3px `--accent` 바 |
| PC 팔레트 | 입력 + 지우기, 결과 섹션(메모/명령), 하단 키 힌트 |
| PC 설정 | 좌측 섹션 메뉴 + 카드. Drive(실선, 사용 중) vs Pro(점선, 업그레이드가 주 버튼) |
| 모바일 잠금 | 지문 원형 버튼 중앙, 보조 "비밀번호로 열기" |
| 모바일 목록 | 명조 제목, 상태 뱃지, 검색(지우기), 폴더 칩, 하단 고정 "+ 새 메모" |
| 모바일 편집 | 상단 우측 `완료`(주 버튼), 키보드 위 툴바 40px, 하단 저장 상태 |
| 모바일 설정 | 동기화 → 백업 → 보안 → 내 데이터 순. 토글은 2택일에만 |
