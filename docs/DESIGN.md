# 디자인 시스템

캔버스(최종 디자인, 8화면): https://claude.ai/artifact/KjaDp48c7yc3aoxnL79VrM
`apps/web/src/styles/tokens.css`에 아래 값을 그대로 옮긴다. 참고한 가이드: 모바일 UI 가이드(서윤/최철호), Consumer Web UI/UX 가이드(NN/G·Baymard·GOV.UK·WCAG 2.2 기반), Beyond the Template 2026–2030.

## 방향
- 축: **CALM × UTILITY**. 한 문장: **"흰 종이 위의 인장."** 순백 바탕, 선 대신 옅은 회색 채움, 빨강은 도장과 '오늘'에만.
- 브랜드 문장: "개발자도 못 보는 메모장." 조용하고, 가볍고, 정확하다.
- 변경 기록
  - 2026-11 초: 크림색 종이 + 명조 + 봉랍 흙색 + 둥근 흰 카드 → 생성형 디자인의 흔한 조합이라 교체.
  - 2026-11 중: "문서와 도장"(회백 + 청흑 + 각진 모서리) → 사용자 피드백 "딱딱하다", "노션 느낌" → 교체.
  - 2026-11-22: 순백 + 차가운 중성 회색 + 둥근 컨트롤. 보기 방식(목록·카드·캘린더)과 빠른 메모 추가. 참고: Bear(장식 없는 흰 바탕), NotePlan(메모와 캘린더를 한 화면에), Diarly(날짜 있는 기록과 없는 메모를 나눔).
  - 2026-11-25: PC 가로 상단 바를 없애고 사이드바로 모음. 캘린더를 "작은 달력 + 일정 목록"으로 다시 만듦.
- 장식은 한 곳에만: 가는 선 인장. 그 밖의 화면에는 장식을 넣지 않는다.

## 따르는 원칙 (출처)
- **테두리와 상자를 줄이고 여백·굵기·크기로 위계를 만든다.** 회색은 한쪽으로 살짝 물들인다(여기서는 차가운 쪽). — Refactoring UI (Wathan, Schoger)
- **얻지 못한 주목을 두고 경쟁하지 않는다.** 내비게이션과 도구는 조용하게, 내용이 앞에. — Linear 디자인 팀
- **모든 요소에 목적이 있고 기능이 겹치지 않는다.** 같은 일을 하는 버튼을 두 곳에 두지 않는다. — Things 3 (Cultured Code)
- **결과가 바로 보이면 알림을 띄우지 않는다.** 빠른 메모는 목록에 나타나는 것이 피드백이다. 토스트는 되돌리기가 필요한 동작에만.
- 검토 방법: `node apps/web/scripts/shots.mjs <폴더> [light|dark]`로 주요 화면을 찍어 놓고 본다.

## 토큰
```css
:root {
  --paper: #FFFFFF;      /* 앱 바탕 */
  --surface: #FFFFFF;    /* 편집기·입력·대화상자 */
  --surface-2: #F7F8FA;  /* 사이드바, 묶음 목록 바탕 */
  --fill: #F1F3F5;       /* 선택된 항목, 칩, 세그먼트 트랙 */
  --fill-hover: #F5F6F8; /* 마우스를 올린 행 */
  --ink: #15171C;        /* 본문 */
  --ink-2: #3D424C;      /* 설명 */
  --muted: #6A707C;      /* 보조 (흰 바탕 대비 4.9:1) */
  --line: #E7E9ED;  --line-2: #EFF1F4;  --line-strong: #CDD1D8;
  --accent: #C8322B;     /* 인주 빨강: 인장, 오늘, 일요일 */
  --accent-soft: #FCEBEA;
  --primary: #15171C;    /* 주 버튼 */
  --ok: #1F7A50;  --warn: #8A5A00;  --danger: #B42318;
  --radius-s: 8px; --radius-m: 10px; --radius-l: 14px;
  --font-sans: 'IBM Plex Sans KR';  --font-serif: 'Hahmlet';  --font-mono: 'IBM Plex Mono';
}
```
- 다크 테마 값은 `apps/web/src/styles/tokens.css`.
- 현재 위치·선택은 **채움**(`--fill`, 사이드바는 흰 알약 + 옅은 그림자)으로 표시한다. 붉은 막대는 쓰지 않는다.
- 세그먼트는 회색 트랙 안의 흰 손잡이. 검게 반전하지 않는다.
- 칩·토스트·뱃지 버튼은 완전한 알약(999px). 버튼과 입력은 8~10px, 카드·대화상자는 14px.

## 타이포
- 화면 제목·메모 제목: `--font-sans` 700, letter-spacing -0.02em. 명조(`--font-serif`)는 잠금 화면 문장과 인장에만.
- 본문: `--font-sans` 400, 15px(PC) / 16px(모바일), line-height 1.7 이상.
- 보조 텍스트 12–13px, 색 `--muted` 이하로 내려가지 않음.

## 문구
- 정보를 가운뎃점으로 줄줄이 잇지 않는다. 문장으로 쓰거나 요소를 나눈다.
- 버튼은 누르면 일어나는 일을 그대로 쓴다. 화살표 글자 대신 아이콘. 이모지를 UI 기호로 쓰지 않는다.

## 키 장부 화면 (2026-11-25, 캔버스도 이 기준으로 다시 그림)
- 키 이름과 값은 고정폭(IBM Plex Mono), 나머지는 IBM Plex Sans KR.
- 키 줄: 이름 + 환경 칩(테두리만) / 서비스 이름 + 가린 값 + 살펴볼 것 칩(붉은색) + 오른쪽에 복사 단추. 줄을 누르면 열리고 복사 단추는 열지 않고 복사한다.
- 키 상세의 주 버튼은 "복사" 하나. "보기"는 보조.
- 경고는 목록에서는 붉은 칩 한 개, 설명 문장은 그 키를 열었을 때만(옅은 붉은 상자).
- 공개해도 되는 키는 초록 칩 "공개 가능". 붉은색은 사용자가 뭔가 해야 할 때만 쓴다.
- 사고 모드: 큰 숫자 `2 / 7` + 진행 막대 + 체크리스트. 끝낸 줄은 취소선.
- 사이드바: 살펴볼 것 / 모든 키 / 모든 메모 / 일정 / 프로젝트 … 맨 아래 사고 모드, 휴지통.

## 보기와 조작 (선택의 자유)
- 첫 화면은 **오늘**: 사이드바 맨 위, 모바일 칩 맨 앞. 가운데 열에 묶음(작은 회색 제목 + 메모 행)을 위에서 아래로 쌓는다. 보기 방식·정렬은 여기서 숨긴다. 묶음 순서와 판단 기준은 `docs/KPI.md`.
- 할 일 행: 체크박스 + 내용 + 아래에 작은 회색으로 출처 메모. 체크하면 알림 없이 행이 사라진다(결과가 보이므로).
- 날짜 말 칩: 빠른 메모 칸 오른쪽에 `11월 26일 (목) ×`. 자동으로 한 일은 미리 보여주고 한 번에 되돌릴 수 있어야 한다.
- 보기 방식: **목록 / 카드 / 캘린더** 세그먼트, 사용자가 고르고 기억한다. 카드·캘린더는 가운데 열을 넓게 쓰고, 메모를 고르면 오른쪽에 편집기가 열린다(× 로 닫음).
- 캘린더 기준: **일정 날짜 / 작성일**. 일정 날짜가 없으면 제목이 `YYYY-MM-DD`인 오늘의 메모를 그 날로 본다.
- 캘린더: 왼쪽에 **작은 달력**(날짜 + 메모 수만큼 점, 최대 3개), 오른쪽에 **고른 날의 메모**와 **다가오는 일정**(30일, 날짜별 묶음). 큰 칸에 제목을 잘라 넣지 않는다. 오늘은 붉은 원, 고른 날은 검은 테두리. 방향키로 날짜 이동. 좁으면 위아래로 쌓는다(컨테이너 쿼리 720px).
- 빠른 메모: 목록 위 입력칸. Enter = 추가하고 계속 쓰기, Shift+Enter = 추가하고 열기. 캘린더에서 고른 날이 있으면 그 날짜로.
- 메모의 날짜는 편집기 태그 줄의 날짜 칩으로 정하고 × 로 지운다.
- 정렬은 목록·카드에서만 작은 선택 상자로. 사이드바·모바일 칩에 "일정"(날짜 있는 메모, 가까운 날부터).

## 컴포넌트 규칙
- **주 버튼은 화면당 1개** (`--primary` 잉크 배경, 500). 나머지는 테두리 버튼 또는 링크. 같은 강조 레벨 반복 금지.
- **누를 수 없는 버튼은 색을 뺀다** (`--line-2` 배경, `--muted` 글자). 흐린 주 버튼처럼 보이면 안 된다. 왜 못 누르는지는 바로 위 안내문이 말한다.
- **즉시 바뀌는 둘 중 하나는 스위치** (자동 잠금). 체크박스는 동의와 여러 개 고르기에만.
- **여러 단계 입력은 단계 수를 보여준다** (처음 설정 "1 / 2 단계").
- 선택·정렬·주기처럼 옵션 ≤5개는 **세그먼트 컨트롤**(눌린 항목 `--ink` 배경 + 흰 글자). 드롭다운은 7개 이상일 때만.
- 상태 표시: 점(8px) + 텍스트, 색은 `--ok/--warn/--danger`. 테두리 알약은 버튼처럼 보여서 쓰지 않는다. 색만으로 상태를 구분하지 않는다.
- 저장/동기화 피드백은 텍스트로("방금 전 이 기기에 저장됨"). 아이콘만 두지 않는다.
- 입력창: 높이 44–48px, 테두리 `--line-strong`, **지우기(×) 버튼 필수**, 포커스 링 2px `--ink`.
- 오류: 해당 필드 바로 아래에 "무엇이 왜 틀렸고 어떻게 고치는지" 한 줄 + 예시.
- 빈 상태: 설명 1줄 + 다음 행동 버튼 1개 ("첫 메모 쓰기", "필터 초기화").
- 로딩: 레이아웃 유지하고 스켈레톤. 화면을 가리는 스피너 금지.
- 위험 동작(삭제·연결 해제): `--danger` 테두리 버튼 + 확인 단계. 숨기지 않되 주 버튼 스타일로 만들지 않는다.
- 터치 타겟 44px 이상, 모바일 `완료`는 상단 내비게이션 우측(키보드에 가려지지 않게).
- 모바일 상단 바: 왼쪽은 이동(뒤로 + **목적지 이름**: "목록", "메모"), 오른쪽은 이 화면의 작업 1–2개. 같은 곳으로 가는 버튼을 두 개 두지 않는다. 브레드크럼 없음.
- 모바일 대화상자는 아래에서 올라오는 시트. PC는 가운데 대화상자.
- 모션: 상태 전환 150–200ms, `prefers-reduced-motion`이면 전부 끔.
- **확인 창은 앱 안 대화상자**(`ui.confirm` / `ui.prompt`, `components/DialogHost.tsx`). 브라우저 기본 `confirm`/`prompt`/`alert`는 쓰지 않는다. 위험 동작의 확인 버튼은 `--danger` 테두리, 기본 포커스는 취소.
- **되돌릴 수 있는 동작은 묻지 않고 실행한 뒤 토스트로 "되돌리기"를 준다** (휴지통으로 보내기). 되돌릴 수 없는 동작(계정 삭제, 연결 해제)만 확인 단계를 둔다.
- 토스트: 하단 가운데, `--ink` 배경, 6초 뒤 사라짐, 동작 버튼은 1개까지.
- 아이콘은 `components/Icons.tsx`의 선 아이콘(1.5px, currentColor)만. 이모지를 UI 기호로 쓰지 않는다.

## 고유 패턴
- **"서버가 보는 것" 패널** (Memory Boundary 차용): 설정 동기화 섹션에 "✓ 볼 수 있음 / ✕ 볼 수 없음" 두 줄. 제로-널리지를 말이 아니라 화면으로 보여준다.
- 편집기 상단 작은 자물쇠 아이콘 + "이 기기에서 암호화됨 · 서버는 내용을 볼 수 없음".
- 충돌 사본: 목록 행 아래 `--accent-soft` 배경 작은 뱃지 "⚠ 충돌 사본 1개 · 폰에서 동시에 수정됨".
- 편집기 표기: 체크박스 `[ ]`/`[x]`는 상자(완료는 `--ok` 채움 + 줄 흐리게), `[[링크]]`는 `--accent-soft` 배경, `#태그`는 `--accent` 글자. 글자는 지우지 않고 모양만 입힌다(마크다운 원문 유지).
- 편집기 본문 폭: 좁게 620 / 보통 760 / 넓게 제한 없음 (`--editor-width`, 설정 > 모양). 가운데 정렬.
