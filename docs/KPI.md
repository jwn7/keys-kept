# 왜 이 앱을 쓰는가, 그리고 그것을 재는 법

## 질문
기존 메모 앱(Keep, Apple 메모, Notion)과 기존 암호화 메모 앱(Standard Notes, Notesnook)이 있는데 왜 이걸 쓰는가.
"암호화된다"는 이유로는 부족하다. 사람들은 **보안 때문에 오지만 불편 때문에 떠난다.**

## 조사에서 나온 것 (2026-11)
| 사람들이 떠나는 이유 | 이 앱의 답 | 상태 |
|---|---|---|
| 동기화가 멈추거나 메모가 사라질까 불안 | 로컬 우선, 충돌은 사본으로 보존, 버전 기록, 동기화 상태를 항상 글자로 표시, 자동 로컬 백업 | 있음 |
| 다른 앱으로 옮기기 어렵다 | 표준 age 백업, 옵시디언 호환 zip, 마크다운 가져오기 | 있음 |
| 매번 비밀번호를 치기 귀찮다 | 패스키(지문·Windows Hello) | 있음 |
| 검색이 약하다(여러 단어 교집합 불가) | 여러 단어 모두 포함 + 순위 | 있음 |
| "암호화된다"는 말을 믿을 근거가 없다 | **서버가 보는 모습 보기**: 내 메모가 서버에 어떤 글자로 올라가는지 그대로 보여준다 | 이번에 추가 |
| 적을 때 느리다, 열 이유가 없다 | **오늘 화면**(오늘 일정·오늘 쓴 메모·다가오는 일정) + 열자마자 바로 적는 빠른 메모 | 이번에 추가 |

끌리는 지점은 네 가지로 좁힌다.
1. **Keep만큼 빨리 적힌다** (적는 속도)
2. **매일 열 이유가 있다** (오늘 화면)
3. **적어 두면 앱이 다시 꺼내 준다** (아래 표)
4. **못 본다는 것을 눈으로 확인할 수 있다** (증명)

## 자동으로 도와주는 것
사용자가 스스로 묻는 질문에 앱이 먼저 답한다. 전부 기기 안에서 계산한다(서버 AI 없음).

| 사용자의 질문 | 앱이 하는 일 | 어디서 |
|---|---|---|
| 내일 뭐 해야 하지? | 오늘 화면의 다가오는 일정(내일부터 8일) | 오늘 |
| 적어 둔 할 일이 어디 있더라? | 모든 메모의 안 끝난 체크박스를 모아 보여주고 거기서 체크 | 오늘 > 할 일 |
| 회의에서 누가 뭘 하기로 했지? | `- [ ] @민수 보고서`의 담당자가 할 일에 그대로 보임, 회의록 틀 | 오늘 > 할 일, 팔레트 |
| 날짜 넣기 귀찮다 | "내일 치과 3시"라고 쓰면 날짜가 붙는다 | 빠른 메모 |
| 이거랑 관련된 자료가 뭐였지? | 태그·제목이 겹치는 관련 메모, 나를 링크한 메모 | 편집기 아래 |
| 배운 걸 자꾸 잊는다 | `#복습` 메모를 1·3·7·14·30일째에 다시 보여줌, 학습 노트 틀 | 오늘 > 다시 볼 메모 |
| 하루를 어떻게 시작하지? | 하루 계획 틀(꼭 할 3가지, 루틴 체크, 돌아보기) | 팔레트 |

하지 않는 것: 앱이 닫힌 동안의 푸시 알림(서버가 일정 내용을 알아야 함), 서버·외부 AI 요약(평문이 기기를 떠남).

## KPI
서버가 없고, 사용 기록을 밖으로 보내지 않는다(보내면 제품 약속과 충돌). 그래서 **기기 안에서만 세고 사용자에게 보여주는 수치**로 잰다. 사용자 테스트(5명)에서는 설정 > 내 사용의 "수치 복사"로 자발적으로 받는다.

| KPI | 뜻 | 목표 | 재는 곳 |
|---|---|---|---|
| 첫 메모까지 시간 | 처음 설정을 끝낸 뒤 첫 메모를 저장할 때까지 | 60초 이내 | `metrics.firstNoteAt - installedAt` |
| 열고 나서 첫 메모까지 | 잠금을 푼 뒤 첫 메모 저장까지(중앙값) | 10초 이내 | `metrics.captureMs` |
| 주간 사용일 | 최근 7일 중 앱을 연 날 | 4일 이상 | `metrics.activeDays` |
| 4주 유지 | 최근 28일 중 앱을 연 날 | 12일 이상 | `metrics.activeDays` |
| 패스키 사용 비율 | 잠금 해제 중 비밀번호를 안 친 비율 | 지원 기기에서 70% 이상 | `metrics.unlocks` |
| 빠른 메모 비율 | 새 메모 중 빠른 메모로 만든 비율 | 참고용(적는 방식 파악) | `metrics.quickCaptures / captures` |

수치는 `localStorage`의 `vault.metrics`에 개수와 시각만 둔다. 메모 내용·제목은 들어가지 않는다. 계정 삭제 때 같이 지워진다.

## 디자인 쪽 판단 기준
- 열었을 때 3초 안에 "오늘 뭐가 있나"가 보이는가 → 오늘 화면이 첫 화면.
- 아무 것도 누르지 않고 바로 글자를 칠 수 있는가 → 잠금 해제 후 빠른 메모에 커서.
- 못 미더운 사람에게 10초 안에 증거를 보여줄 수 있는가 → 메모 메뉴 > 서버가 보는 모습.
- 자동으로 한 일은 미리 보이고 한 번에 되돌릴 수 있는가 → 날짜 말 칩의 ×.
