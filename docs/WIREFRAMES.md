# 와이어프레임

캔버스(편집 가능, Play로 화면 이동): https://claude.ai/artifact/KjaDp48c7yc3aoxnL79VrM

## PC (1280 × 800, 유동 레이아웃)
| 화면 | 파일 | 요점 |
|---|---|---|
| 잠금 해제 | `PC-Unlock` | 비밀번호만. "열쇠 만드는 중 0.5초" 안내, 자동 잠금 체크, "백업 파일로 복구" 링크 |
| 메인 | `Main` | 3열: 폴더/태그 사이드바(200) · 목록(320) · 편집기. 상단 상태 뱃지(Drive 동기화됨/오프라인), 검색창 = `Ctrl+K`. 편집기 아래 백링크 패널, 하단 "버전 기록" 버튼. 목록의 충돌 사본은 빨간 줄 |
| 커맨드 팔레트 | `PC-Palette` | 메모 검색 결과 + 명령(새 메모 Ctrl+N, 오늘의 메모 Ctrl+D, 동기화, 백업, 잠금 Ctrl+L) |
| 설정 | `PC-Settings` | 동기화(Google Drive 사용 중 / Pro 업그레이드 카드 / 기기 목록), 메일 백업, 보안(자동 잠금·비밀번호 변경·복구키), 내 데이터(옵시디언 내보내기·가져오기·계정 삭제) |

## 모바일 (390 × 844)
| 화면 | 파일 | 요점 |
|---|---|---|
| 잠금 해제 | `M-Unlock` | 지문 버튼 중앙, "비밀번호로 열기" 보조, 새 폰/5회 실패 안내 |
| 목록 | `M-List` | 제목 + 상태 뱃지 + 검색, 폴더 칩 가로 스크롤, 목록, 하단 "+ 새 메모" |
| 편집 | `M-Editor` | 제목·태그·본문, 백링크 가로 스트립, 키보드 위 툴바(제목/체크/[[링크]]/#태그/코드), "로컬 저장됨" 푸터 |
| 설정 | `M-Backup` | 동기화(Drive 카드 / Pro 카드), 메일 백업(".age 파일 만들어 공유하기"), 보안, 내 데이터 |

## 흐름
- PC: 잠금 해제 → 메인 ⇄ 설정, 메인에서 Ctrl+K
- 모바일: 잠금 해제 → 목록 → 편집 → 목록 → 설정
- 캔버스 Tweaks의 `offline` 토글로 오프라인 상태 뱃지 확인 가능

## 디자인
캔버스는 최종 디자인(종이색 바탕 · 먹색 · 봉랍 붉은색 액센트 · Noto Serif/Sans KR)까지 반영돼 있다. 토큰과 컴포넌트 규칙은 `docs/DESIGN.md`.
